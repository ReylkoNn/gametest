# ⚔ The King's Order — локальная RP-игра (NSFW, offline-first)

Локальное веб-приложение для ролевой игры с чат-ботом через **твой API**.
Работает **без облака и без сборки**: всё локально, данные — в браузере,
LLM-запросы идут через локальный proxy (ключ не утекает в сторонние сервисы,
нет проблем с CORS).

## Запуск

```bash
python3 server.py          # → http://localhost:8000
# или
PORT=9000 python3 server.py
```

Открой `http://localhost:8000` в браузере (Chrome/Firefox/Edge).

> Без `server.py` можно открыть `index.html` напрямую, но тогда нужен режим
> «Напрямую из браузера» в настройках, и провайдер должен разрешать CORS.
> Рекомендуемый режим — локальный proxy.

## Фишки чата
- **Приветствие из `first-message.txt`** — бот первым открывает сцену при новой игре текстом из файла `first-message.txt` в корне репозитория (твой собственный first message от нейросети; отредактируй файл — при следующем открытии страницы приветствие обновится, пока ты не написал первым). Файл подставляется **как есть, без фильтров**; если файла нет — дефолтное приветствие из `js/data.js`.
- **Только русский** — OUTPUT RULES обязывают модель отвечать всегда по-русски, даже если игрок пишет на другом языке.
- **Красивый вывод** — markdown в пузырях: *курсив* для действий, **жирный**, цитаты, разделители; плюс санитайзер вырезает мусор из шаблона (`</CHARACTER_DESCRIPTION>`, `[Харизма: 0.7]`, `Шар Инициативы: […]`, `{{…}}`) и из истории перед моделью.
- **🌡 Температура** — слайдер в композере + пресеты в настройках (0 логично → 1.7 хаос).
- **Аватарка бота** — своя картинка в настройках (обрезается в круг 128×128) или дефолтная `assets/viora-avatar.jpg`; в топбаре и в каждом сообщении.
- **⏹ Стоп** — кнопка отправки во время генерации становится «Стоп»: частичный ответ сохраняется, шкалы не трогаются.
- **↓ К последнему сообщению** — всплывает, когда прокрутил вверх.
- История ответов теперь реально уходит модели (бот помнит, что сам говорил).

## Настройка API (⚙ API в чате)

Нужен любой **OpenAI-совместимый** эндпоинт:

| Провайдер | Base URL | Модель (пример) |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| KoboldCpp (local) | `http://localhost:5001/v1` | любая HF-модель |
| Ollama (local) | `http://localhost:11434/v1` | `llama3.1` |
| llama.cpp server | `http://localhost:8080/v1` | из `--model` |

Ключ хранится в localStorage твоего браузера. Кнопка **Проверить** шлёт
запрос `/models`.

## Системы

### ✨ Trust — умное начисление доверия
- Шкала **0–54** с 11 уровнями (Hostile Rival → In Deep Love), текущий
  уровень в топбаре и бейдж «Вы здесь» в списке уровней.
- **Правила повышения/понижения** вшиты в system-prompt: бот сам двигает
  шкалу строкой `<<STATS {"trust_delta":…}>>` в конце ответа
  (с причиной в `note`).
- **Умный множитель** (`trust.smart`): при росте шкалы плюсы смягчаются
  (×1.0 → ×0.45), минусы усиливаются (×1.0 → ×1.35) — влюбляться легко,
  а потерять доверие на вершине дорого.
- Ручная правка (✎ в карточке Trust): ±1/±2/±5 или точное число.
- **Откат**: «⟲ Перегенерировать» и переключение вариантов (⇄) восстанавливают
  шкалы/время/одежду к состоянию **до** ответа — как в правиле
  «шакалы восстанавливаются с этой точки».

### 👗 Гардероб (раздевание)
- Отдельные списки для персонажа (14 состояний: от Fully Dressed до
  Completely Nude) и игрока (включая `???`).
- Выбор = «⏳», применяется **с следующего сообщения** (как в скине).
- Бот может двигать одежду сам через `npc_clothes` / `player_clothes` —
  только валидными метками и только когда сцена дошла.

### 🕐 Время
- День + часы: 10 периодов (Early Morning 6:00 … Late Night 22:00).
- **+5 минут за каждое активное действие** (галочка «⏱ без времени»
  отключает шаг для конкретной отправки). Пересечение полуночи = новый день.
- Редактор дня/времени: степпер дня, чипы периодов, ±1 час — тоже
  «вступает в силу со следующего сообщения».
- Статус-строка под ответом: `⏱ Day 1 · 23:40 (+5)` и все изменения.

### 📍 Локации
- 15 локаций из скина, бейдж «Вы здесь», отложенное применение.

### 🎛 Тумблеры
- **Интерактивные функции** — выкл = обычный персонаж без шкал.
- **Скрыть показатели** — шкалы скрыты, но продолжают работать.
- **Изменения статуса в чате** — строки под ответом.

## Сохранение
- Автосохранение в `localStorage` + экспорт/импорт JSON (карточка
  «Сохранение»). «Новая игра» сбрасывает к дефолту.

## Контент / безопасность
Игра 18+, контент генерируется твоей моделью. Приветствие хранится в
`first-message.txt` в самом репозитории (чтобы не нарушать политику
площадки) и подставляется в чат без фильтров. Промпт обязывает модель
отвечать только по-русски, запрещает упоминать внутренние `<<STATS>>`
в тексте и говорить за игрока. Все личные данные остаются на твоей
машине.
